# Понятные инструкции от Мистера Кибби

Небольшой статический блог с инструкциями, разбором понятий и другими материалами.

## Структура

- `index.html` — главная страница со списком всех материалов, поиском и фильтрами.
- `articles/` — отдельные HTML-страницы статей.

## Как добавить статью

1. Создайте новый HTML-файл в каталоге `articles/`.
2. Добавьте карточку со ссылкой на него в `index.html`.
3. Укажите категорию карточки (`guide` или `ideas`) и поисковые ключевые слова в атрибуте `data-search`.

Сайт не требует сборки или серверной части: его можно размещать как статический сайт, например через GitHub Pages.
