# Мистер Кибби — библиотека понятных вещей

Статический блог с инструкциями, пошаговыми гайдами и разбором идей. Публикуется через GitHub Pages: сборщик, сервер и база данных не требуются.

## Структура проекта

- `index.html` — главная страница: знакомство с проектом, рекомендуемый материал и последние публикации.
- `library/index.html` — каталог со строкой поиска и фильтрами по типам материалов.
- `articles/` — самостоятельные HTML-статьи. Существующие адреса материалов сохранены.
- `data/articles.json` — единый каталог: заголовки, описания, категории, теги и поисковые ключи.
- `assets/css/tokens.css` — дизайн-токены: цвета, типографика, размеры и радиусы.
- `assets/css/site.css` — общая визуальная система, адаптивная оболочка, главная, каталог и оформление статей.
- `assets/css/pages/` — стили уникальных схем и иллюстраций отдельных статей.
- `assets/js/site.js` — общая навигация, подвал, каталог, поиск, фильтры и индикатор чтения.
- `assets/favicon.svg` — фирменная иконка.
- `templates/article-template.html` — шаблон новой статьи.
- `404.html` — фирменная страница для несуществующих адресов.
- `ARTICLE_STYLE.md` — редакционный стандарт.

## Дизайн-система

Дизайн построен на графитовой палитре с коралловым акцентом. Общие цвета и параметры находятся в `assets/css/tokens.css`. Внешний вид страниц, компонентов и адаптивное поведение задаются в `assets/css/site.css`.

Минимальный размер любого текстового элемента интерфейса — **14 px**. Основной текст статей и описаний крупнее, чтобы длинные материалы было удобно читать.

Шапка и подвал добавляются общим скриптом через элементы `data-site-header` и `data-site-footer`. Каталог главной и страницы библиотеки формируется из `data/articles.json`.

## Как добавить статью

1. Скопируйте `templates/article-template.html` в `articles/` и задайте файлу адрес, например `new-topic.html`.
2. Заполните метаданные и содержимое. Не добавляйте встроенные блоки `style` или `script`: общая оболочка уже подключена.
3. Добавьте объект в `data/articles.json`. Поле `slug` должно совпадать с именем HTML-файла без расширения.
4. Для специальной схемы создайте CSS в `assets/css/pages/` и подключите файл после `tokens.css`, но перед `site.css`.
5. Проверьте страницу статьи, библиотеку, поиск, фильтры и мобильную версию.

## Редакционный принцип

Статьи рассчитаны на людей, которые впервые сталкиваются с темой. Объясняем простыми словами и последовательно: определяем термины, разбираем процесс на небольшие шаги, приводим примеры и отдельно отмечаем распространённые ошибки.

Правила написания материалов собраны в [ARTICLE_STYLE.md](ARTICLE_STYLE.md).
