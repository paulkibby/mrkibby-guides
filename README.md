# Понятные инструкции от Мистера Кибби

Статический блог с подробными инструкциями, разбором понятий и другими материалами. Сайт публикуется через GitHub Pages и не требует сборщика или сервера.

## Архитектура

- index.html — главная страница: структура и контент.
- articles/ — самостоятельные HTML-материалы.
- data/articles.json — названия, описания, категории и данные карточек каталога.
- assets/css/tokens.css — цвета, шрифты, радиусы и базовые переменные.
- assets/css/site.css — общая тема, компоненты, сетки и адаптивность.
- assets/css/pages/ — стили специальных схем и иллюстраций конкретных статей.
- assets/js/site.js — общая шапка, подвал, каталог, поиск, фильтры и прогресс чтения.
- templates/article-template.html — стартовый шаблон новой статьи.
- ARTICLE_STYLE.md — редакционные правила.

## Как устроен дизайн

- Глобальное оформление находится в assets/css/site.css.
- Дизайн-токены — палитра, шрифты и размеры — находятся в assets/css/tokens.css.
- В assets/css/pages/ остаются только стили уникальных схем и иллюстраций. Они не отвечают за общую оболочку сайта.
- Общая шапка и подвал подключаются через assets/js/site.js. Поэтому их разметка не дублируется в каждой статье.
- Каталог главной страницы, фильтры и поиск используют данные из data/articles.json.

Для следующего редизайна сначала меняйте tokens.css и site.css. HTML всех статей переписывать не требуется. CSS статьи нужен только тогда, когда в ней есть особая схема или интерактивная иллюстрация.

## Как добавить статью

1. Скопируйте templates/article-template.html в папку articles/ и задайте файлу понятный адрес, например new-topic.html.
2. Заполните метаданные и содержимое. Не добавляйте в файл встроенные блоки style или script: оформление и общие функции уже подключены.
3. Добавьте объект статьи в data/articles.json. Поле slug должно совпадать с именем HTML-файла без расширения.
4. Если статье нужна уникальная схема, создайте для неё CSS в assets/css/pages/ и подключите после tokens.css, но перед site.css. Общие стили туда не переносите.
5. Проверьте главную страницу, поиск, фильтры и мобильную версию.

## Редакционный принцип

Статьи рассчитаны на читателя, который впервые сталкивается с темой. Объясняем простыми словами и последовательно: определяем термины, разбираем процесс на небольшие шаги, приводим примеры и отдельно отмечаем распространённые ошибки.

Правила написания новых материалов собраны в [ARTICLE_STYLE.md](ARTICLE_STYLE.md).
