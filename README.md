# Понятные инструкции от Мистера Кибби

Небольшой статический блог с инструкциями, разбором понятий и другими материалами.

## Редакционный принцип

Статьи рассчитаны на читателя, который впервые сталкивается с темой. Объясняем простыми словами, подробно и последовательно: определяем термины, разбираем процесс на небольшие шаги, приводим понятные примеры и отдельно отмечаем распространённые ошибки.

Правила написания новых материалов собраны в [ARTICLE_STYLE.md](ARTICLE_STYLE.md).
